CLIENT-SIDE ML PIPELINE & CYBERSECURITY ETHICS

Deepfake Awareness & Static GitHub Pages Architecture

How local signal analysis, the optional Detectra image model, and MediaPipe landmarks run in the browser.

Browser ML & Fallback Engine Design

  • Inline Blob Web Worker (`WorkerML`): Loads @huggingface/transformers via jsDelivr ES modules with automatic webgpu → wasm fallback so the main UI thread never freezes.
  • MediaPipe FaceLandmarker (`@mediapipe/tasks-vision`): Tracks 478 3D facial vertices and jawOpen / mouthClose blendshapes across 12 keyframes for true audio-video lip-sync correlation.
  • Offline Fallback: If the image model or MediaPipe files cannot load, local ELA, metadata, stylometry, and DSP checks remain available. Image model results are marked unavailable rather than guessed.

Privacy Guarantee & Model Limitations

  • Local Media Processing: Media is processed in browser memory and is not uploaded to a DeepGuard server. App libraries and optional model files are fetched from public CDNs.
  • Anomaly Index ≠ Certainty: Automated scores reflect measured signal and neural deviations—always verify financial or identity requests via a secondary trusted channel.
  • Metadata Stripping Context: Social platforms strip EXIF and C2PA manifests during recompression; missing metadata alone is never treated as proof of forgery.
